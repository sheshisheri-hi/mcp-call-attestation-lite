Pin ≈ wax seal

MCP host/client hashes tools/list at connect. A mid-session schema swap breaks the seal.

Envelope ≈ label

HMAC in _meta binds agent id + tool name + args digest. Swapped args tear the label.

Chain ≈ receipts

prevDigest → thisDigest. The MCP server numbers what it admitted. Not a door key.
